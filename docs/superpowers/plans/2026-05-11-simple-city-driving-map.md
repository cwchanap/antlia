# Simple City Driving Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a reusable simple city map scene to the Antlia bus driving demo, with wide roads, collisions, and visible bus stop markers.

**Architecture:** Keep the C++ driving model and `BusController3D` unchanged. Add a reusable Godot scene at `scenes/simple_city_map.tscn`, then instance it from `scenes/demo_bus_test.tscn`. Add a lightweight Python scene-integrity test that checks the static `.tscn` files for required map structure and verifies that no route, passenger, traffic, stop-detection, or minimap systems are introduced.

**Tech Stack:** Godot 4.6 text scenes, C++ GDExtension project, Python standard library `unittest`, SCons verification.

---

## File Structure

- Create: `tests/test_simple_city_map_scene.py`
  - Owns scene-level regression checks for the reusable city map and demo scene integration.
- Create: `scenes/simple_city_map.tscn`
  - Owns city-blockout environment geometry: ground, road slabs, raised city blocks, boundary barriers, and visual bus stop markers.
- Modify: `.gitignore`
  - Ignores Python bytecode/cache output generated by the scene integrity tests.
- Modify: `scenes/demo_bus_test.tscn`
  - Instances the reusable city map and removes the old single flat ground plane from the demo scene.
- No changes: `src/driving/bus_driving_model.*`
  - Driving math stays unchanged.
- No changes: `src/bus_controller_3d.*`
  - Bus input, movement, tuning, reset, and exposed state stay unchanged.

- [ ] **Step 1: Create the scene test file**

Create `tests/test_simple_city_map_scene.py` with this content:

```python
from pathlib import Path
import re
import unittest


ROOT = Path(__file__).resolve().parents[1]
MAP_SCENE = ROOT / "scenes" / "simple_city_map.tscn"


class SimpleCityMapSceneTest(unittest.TestCase):
    def test_simple_city_map_scene_contains_static_city_grid(self):
        self.assertTrue(MAP_SCENE.exists(), "simple city map scene is missing")
        scene = MAP_SCENE.read_text(encoding="utf-8")

        required_nodes = [
            '[node name="SimpleCityMap" type="Node3D"]',
            '[node name="Roads" type="Node3D" parent="."]',
            '[node name="RoadNorthSouthWest" type="MeshInstance3D" parent="Roads"]',
            '[node name="RoadNorthSouthCenter" type="MeshInstance3D" parent="Roads"]',
            '[node name="RoadNorthSouthEast" type="MeshInstance3D" parent="Roads"]',
            '[node name="RoadEastWestSouth" type="MeshInstance3D" parent="Roads"]',
            '[node name="RoadEastWestCenter" type="MeshInstance3D" parent="Roads"]',
            '[node name="RoadEastWestNorth" type="MeshInstance3D" parent="Roads"]',
            '[node name="CityBlocks" type="Node3D" parent="."]',
            '[node name="BlockSouthWest" type="StaticBody3D" parent="CityBlocks"]',
            '[node name="BlockSouthEast" type="StaticBody3D" parent="CityBlocks"]',
            '[node name="BlockNorthWest" type="StaticBody3D" parent="CityBlocks"]',
            '[node name="BlockNorthEast" type="StaticBody3D" parent="CityBlocks"]',
            '[node name="BoundaryNorth" type="StaticBody3D" parent="Boundaries"]',
            '[node name="BoundarySouth" type="StaticBody3D" parent="Boundaries"]',
            '[node name="BoundaryWest" type="StaticBody3D" parent="Boundaries"]',
            '[node name="BoundaryEast" type="StaticBody3D" parent="Boundaries"]',
        ]
        for node in required_nodes:
            self.assertIn(node, scene)

        stop_nodes = re.findall(
            r'\[node name="BusStop[A-D]" type="Node3D" parent="BusStops" groups=\["bus_stops"\]\]',
            scene,
        )
        self.assertEqual(len(stop_nodes), 4)

        forbidden_runtime_systems = [
            "Route",
            "Passenger",
            "TrafficLight",
            "Minimap",
            "Area3D",
        ]
        for token in forbidden_runtime_systems:
            self.assertNotIn(token, scene)


if __name__ == "__main__":
    unittest.main()
```
